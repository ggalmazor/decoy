Pixelation is a puzzle, not a lock.

A mosaic block is just the average colour of the pixels beneath it. Render guesses in the same font, pixelate them the same way, keep whichever matches: that is all a depixelizer does, and short secrets like passwords and PINs are exactly what it is best at. DECOY takes the puzzle off the table. The pixels in the box come from a different sentence.

Four steps. Zero uploads.

  1. 01

    Open it here

    Drop a PDF, PNG or JPG, or paste a screenshot. Your browser reads it straight from disk. There is no server to send it to.

  2. 02

    Box the secret

    Drag over a password, an IBAN, a phone number. DECOY measures the box and works out how many characters fit in it.

  3. 03

    Pick a mood, reroll

    Decoys are generated to the size of the box, so the mosaic looks like it belongs there. Reroll until it is perfect, or type your own.

  4. 04

    Export it flattened

    The page is re-drawn as an image with the real pixels gone. No hidden text layer, no metadata, nothing left to un-blur.

Questions, asked suspiciously

Does my file get uploaded?

No. DECOY is a static page. Files are opened with the browser’s File API, drawn onto a canvas and exported from that canvas. Load it once and it keeps working with the network unplugged.

Can anyone recover what I covered?

Not from the export. The box is filled from the decoy text alone, so the original pixels never reach the mosaic. PDFs are flattened to images, so no text layer survives underneath either.

Where do the insults come from?

Phrase templates, filled in and trimmed until they fit the box. Pick a mood, switch profanity off, or write your own line.
